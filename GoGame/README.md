# 弈 · GoGame

![Made by GLM 5.3](https://img.shields.io/badge/Made%20by-GLM%205.3-d8503a) ![零依赖](https://img.shields.io/badge/零依赖-零构建-7d7360)

水墨风格的围棋教学对弈游戏。零基础十二课入门，百局名谱打谱研习，人机对弈、双人手谈、让子棋与数子法终局，开箱即玩。

**Made by GLM 5.3** -- 本项目由 GLM 5.3 设计并实现。

## 运行

无需构建、无任何依赖。任选其一：

```bash
# 方式一：直接双击 index.html（file:// 即可运行）
open index.html

# 方式二：本地服务（推荐，字体加载更稳定）
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080
```

> 联网时自动加载思源宋体 / Cormorant Garamond；离线自动回退系统宋体，不影响使用。

## 功能

### 对弈
- **人机对弈**：四级 AI（入门 25 级 / 初级 15 级 / 中级 5 级 / 高级初段），影响力评估 + 战术捕获启发式
- **双人对弈**：同屏轮流落子
- **棋盘**：九路（入门）/ 十三路 / 十九路（标准）
- **让子棋**：按棋盘自动布置标准让子点位，白先行，贴 0.5 目
- **完整规则**：提子、打劫（禁立即提回）、禁着点（自杀手）、中国规则数子法、贴目（19 路贴 7.5）
- **对局工具**：悔棋（人机模式自动连撤两手）、停一手、中盘认输、棋谱记录、手数显示、坐标开关、音效开关（WebAudio 合成落子声，无音频文件）
- **终局数目**：双方停一手自动进入数子；点击标记死子，实时显示双方目数，确认后展示地域归属与结果

### 学弈（教学）
十二章交互式课程，边看边下，每课配实操任务，完成盖「正解」朱砂印：

| 章 | 主题 | 实操任务 |
|---|------|---------|
| 壹 | 初识棋盘：交叉点、星位、天元 | 落子天元 |
| 贰 | 气与提子 | 提掉角上一子、提掉边上两子 |
| 叁 | 打吃与长 | 长出重围、打吃白棋 |
| 肆 | 禁着点与打劫 | 完整体验一次劫争（寻劫 -> 提回） |
| 伍 | 眼与死活：真眼、假眼、做活 | 做出第二只眼 |
| 陆 | 吃子技巧：双打、关门吃、征子 | 找出双打之点 |
| 柒 | 终局与数目：数子法、贴目 | 地域划分演示 |
| 捌 | 枷吃与封：远一路的温柔一刀 | 枷吃提子 |
| 玖 | 倒扑与接不归：舍与得的智慧 | 倒扑 / 接不归收网 |
| 拾 | 布局之要：金角银边草肚皮、守角挂角 | 三线拆边守角 |
| 拾壹 | 死活常形：直三、曲四、丁四、刀把五 | 直三一点做活 |
| 拾贰 | 官子与胜负手：收官次序、先手后手 | 数目复盘演示 |

学习进度存于浏览器 localStorage。

### 名局（打谱研习）
收录 **130 局**经典对局，横跨四个世纪：

- **江户 · 明治 · 大正**：本因坊算砂、道策、丈和、秀和、秀策、秀哉等御城棋名家
- **昭和 · 平成**：吴清源、高川格、坂田荣男等大师名局
- **AI 时代**：AlphaGo 对李世石、Master 六十连胜、乌镇对柯洁等全部公开对局

目录支持按时代筛选与棋手/赛事搜索；播放器提供播放/暂停、逐手与 ±10 手快进快退、首尾跳转、拖动滑杆、三档速度、坐标与手数显示、键盘操作（← → 逐手，空格播放，Esc 返回）。

> 棋谱数据来自公有领域档案（CWI / Brouwer 公共档案）与 DeepMind 官方发布，以每手两字符的紧凑坐标流编码（66KB 收 130 局），由 `tools/build-kifu.js` 生成，并经规则引擎逐手重放校验。

## 技术

纯原生 HTML / CSS / JavaScript（ES2017），Canvas 渲染棋盘（程序化木纹、径向渐变云子、落子/提子动画），WebAudio 合成音效，零依赖、零构建。

```
GoGame/
├── index.html          页面结构（六个屏幕）
├── css/style.css       水墨视觉系统
├── js/
│   ├── engine.js       围棋规则引擎（提子/劫/禁着点/悔棋/数子）
│   ├── ai.js           AI 对手（影响力评估 + 战术）
│   ├── board.js        Canvas 棋盘渲染器
│   ├── sound.js        WebAudio 音效
│   ├── tutorial.js     十二章课程数据与控制器
│   ├── kifu-data.js    130 局名局数据（紧凑编码，构建期校验）
│   ├── kifu.js         名局目录与打谱播放器
│   ├── game.js         对局控制（人机/双人/数子/结果）
│   └── main.js         路由与全局 UI
└── tools/
    ├── selftest.js     引擎 / AI / 棋谱数据自测
    └── build-kifu.js   名局数据构建脚本（SGF -> 紧凑 JSON）
```

## 自测

```bash
node tools/selftest.js
```

覆盖：提子、打劫、禁着点、数子法计算、悔棋、让子、AI 三级自对弈稳定性、AI 不填真眼、130 局名谱全量重放。

## 规则说明

- 采用**中国规则 · 数子法**：终局结果 = 活棋子数 + 围住空点，黑方贴目补偿先手（19 路 7.5 目 / 13 路 6.5 目 / 9 路 5.5 目；让子局 0.5 目）
- **打劫**采用简单劫判定：一手棋不得重现上一手之前的局面，提劫后对方不可立即提回
