# 手谈 Shoutan · 围棋学堂

![Made by ox Alpha](https://img.shields.io/badge/Made%20by-ox%20Alpha-c04a2e)

一个**单文件、零依赖**的开源围棋应用:人机对弈、零基础互动学堂、死活题练习。
打开 `index.html` 即可使用——无需安装、无需构建、无需网络(字体加载失败时自动回退本地衬线字体)。

![对弈](https://img.shields.io/badge/棋盘-9%2F13%2F19路-d3aa62) ![规则](https://img.shields.io/badge/规则-中国规则%20·%20贴6½目-c04a2e) ![测试](https://img.shields.io/badge/test-node%20test.mjs-passing-7c9a5a)

**Made by ox Alpha** -- 本项目由匿名模型 ox Alpha 设计并实现。

## 功能

### ♦ 对弈
- 9 / 13 / 19 路棋盘,内置启发式电脑棋手(入门 / 业余 / 有段三档)或双人对弈
- 完整规则:提子、禁入点(自杀禁着)、**打劫(位置重复精确判定)**、中国规则数子、贴 6½ 目、双停终局
- 悔棋(终局后亦可悔棋复盘续弈)、停一手、Web Audio 合成的落子/提子音效
- 落子弹跳动画、提子消散动画、最后一手标记、悬停虚子预览、终局目数结算

### ♦ 学堂(7 节互动课)
| 课 | 主题 | 交互目标 |
|---|------|---------|
| 一 | 初识棋盘 | 落下第一颗棋子,认识星位与天元 |
| 二 | 气 | 亲手堵住白棋的一口气,实时显示剩余气数 |
| 三 | 提子 | 堵最后一气提掉白子 |
| 四 | 一网打尽 | 一手双提 |
| 五 | 禁入点 | 亲身体验自杀点被拒绝,再完成提子 |
| 六 | 打劫 | 提劫 → 尝试回提 → 被规则拦下 |
| 七 | 做两只眼 | 直三点眼,救活被围的棋 |

每课实时反馈(气数 / 眼位数),通关盖「通」印章,学习进度存于 `localStorage`。

### ♦ 死活题(5 题)
边路双提 ★ → 一石二鸟 ★★ → 直三做眼 ★★ → 瓮中捉鳖 ★★(AI 白棋会拼死突围)→ 曲三点眼 ★★
提示按钮由内置求解器驱动,走错会给出失败原因。

## 运行

```bash
# 方式一:直接打开
open index.html

# 方式二:本地服务
python3 -m http.server 8000   # 访问 http://localhost:8000
```

## 测试

引擎(规则/AI/数子)为纯函数、无 DOM 依赖,可脱离浏览器测试:

```bash
node test.mjs
```

原理:从 `index.html` 提取脚本,在 Node 中执行(`boot()` 带 `document` 守卫自动跳过),对规则与死活题可解性做断言,并让 AI 自战完整对局冒烟。

## 代码结构(index.html)

```
§引擎    棋盘状态、tryMove/commit、气与连通块、真眼统计、AI 估值、中国规则数子
§音效    Web Audio 合成(无音频资源文件)
§渲染    BoardView:SVG 棋盘绘制、悬停虚子、动画标记
§数据    LESSONS(课程)/ PUZZLES(死活题),坐标为 9 路盘 r*9+c
§控制器  Play(对弈)/ Learn(学堂)/ Puzzle(死活题)+ boot()
```

## 设计说明

- **规则精确性**:打劫采用「局面重复」判定(对比落子前的历史快照),而非"提一子且自身一气"的近似启发式,因此倒扑等提多子场景不会被误禁。
- **AI 定位**:面向初学者的启发式估值(提子/救子/自撞气惩罚/边角线位/就近应援),不追求棋力,追求"像个耐心的陪练"。入门难度会故意放宽选点。
- **已知简化**:终局数子不处理死子判定(结算时提示先提净死子);真眼统计采用正交邻域简化,不含打劫回收等复杂死活。
